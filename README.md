# ASP.NET Core Web API — ლექცია 1

Backend, API, REST და პირველი Web API (.NET 10). ანიმაციური HTML პრეზენტაცია + ლექტორის სცენარი.

| ფაილი | რა არის |
|---|---|
| `index.html` | პრეზენტაცია (43 სლაიდი) |
| `script.html` | ლექციის სცენარი — წასაკითხად / დასაბეჭდად |
| `deck/` | წყარო: სლაიდები (`l3.html`), სცენარი (`script.py`), ძრავი (`engine.*`), ბილდი (`build.py`) |

## გამოყენება

1. გახსენი `index.html` Chrome-ში ან Edge-ში, გადაიტანე პროექტორზე, დააჭირე `F`.
2. დააჭირე `Ctrl+Shift+P` — გაიხსნება **ლექტორის ფანჯარა** სცენარით. დატოვე ლეპტოპის ეკრანზე.
3. ნავიგაცია **მხოლოდ ისრებით**: `→` შემდეგი, `←` წინა. Space, Enter, მაუსის დაჭერა და swipe გამორთულია.

სხვა კლავიშები: `N` შენიშვნები ქვემოთ · `O` ყველა სლაიდი · `A` სლაიდის ყველა ნაბიჯი · `Shift+→` შემდეგი სლაიდი.

## GitHub Pages

Settings → Pages → Branch: `main` / root → Save. პრეზენტაცია გაიხსნება `https://<user>.github.io/<repo>/`-ზე, სცენარი — `/script.html`-ზე.

## ცვლილების შეტანა

სლაიდები: `deck/l3.html`, სცენარი: `deck/script.py`. შემდეგ:

```bash
cd deck && pip install pygments && python3 build.py 3
```

ბილდი ფაილს წერს `../out/`-ში — გადააკოპირე `index.html`-ად.
